# 0.6.0-alpha implementation candidate

The candidate introduces generated whole-run homogeneous and mixed vector
loops, reduces small eager setup, and adds an opt-in bounded CPU context for
selected ufuncs, expressions and deterministic full-array sum. The supported
scope, fallback and numerical semantics are described in the
[parallel guide](../design/parallel-cpu.md). Unsupported layouts and confined
memory use the caller thread. Existing APIs remain single-threaded.

Correctness coverage includes provider-backed fused graphs, layouts, float32
rounding, overlap, worker interruption, shared-scope closure, and NumPy-generated
parallel ufunc and sum references. Verify CI at the actual PR head independently;
local test results do not establish remote checks.

The reference Ryzen 9 5950X campaign has not been run on this revision. The
0.5.0 fusion, allocating and AUTO performance targets remain open, as do 0.6.0
scaling and crossover calibration. A short shared-machine experiment observed
lower fused allocation, but it is not acceptance evidence. See the
[performance status](../benchmarks/M4-performance-status.md) and
[reference protocol](../benchmarks/M4-reference-protocol.md). This status does
not imply a tag, publication or release.

See the [candidate checklist](M4-0.6-release-checklist.md) for validation and
outstanding release evidence.
