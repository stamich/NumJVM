This is an implementation candidate, not an instruction to tag or publish.

- [x] One implementation commit per A01–A05, B01–B05, C01–C05,
  D01–D05, E01–E04 and F01–F03; task dates and author are recorded in Git.
- [x] JDK 25 local `build`, fused-provider tests and the fused-expression
  example completed before the final nested-context and interruption changes.
  Targeted parallel context, stress and expression tests passed afterward.
- [x] NumPy 2.5.4 read all 4,245 generated oracle files; the new parallel
  NumPy fixture check and reference-runner unit tests passed locally.

  and sum API using staged local artifacts, with and without the vector provider.
- [x] A JMH smoke run exercised parallel ADD, CHAIN and SUM. A separate
  shared-machine experiment investigated fused allocation; neither is a
  reference-machine performance claim.
- [ ] Verify build, oracle, CPU backend and quality checks on the actual PR head.
- [ ] Run the [0.6.0 reference campaign](../benchmarks/M4-reference-protocol.md)

- [ ] Re-run and assess the 0.5.0 fusion, allocating and AUTO gates against the
  modified kernels. Complete dot/vecdot reference measurements.
- [ ] Review supported layouts, scope lifetime, nested contexts, native provider
  settings and reproducibility limitations before deciding release readiness.

Do not mark unmeasured targets as passed or silently lower them. In particular,
the E04 commit prepares the campaign; the external reference run remains open.
