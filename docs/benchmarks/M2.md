# M2 CPU measurements

Measured on 30 October 2026, separately from maintainer-requested historical Git timestamps.
Raw files and metadata are in [m2-candidate](m2-candidate/). These are shared cloud
measurements; the final designated-reference performance campaign is outstanding.

## Matrix dispatch experiment

Three forks; three 1-second warmups and five 1-second measurements per fork.
Single-thread OpenBLAS 0.3.29. Timings include packing/copyback where needed.
JMH score errors below are its reported confidence half-widths, not independent proof
of stable dedicated hardware. Java/OpenBLAS measurements ran sequentially.

| Layout | Shape | Java µs/op | OpenBLAS µs/op |
| --- | --- | --- | --- |
| HEAP | 32x32x32 | 40.36 ± 9.35 | 43.54 ± 12.35 |
| HEAP | 128x128x128 | 2047.29 ± 20.43 | 510.98 ± 147.23 |
| AUTOMATIC_NATIVE | 32x32x32 | 37.66 ± 0.75 | 1.28 ± 0.29 |
| AUTOMATIC_NATIVE | 128x128x128 | 3097.76 ± 651.75 | 135.64 ± 65.23 |

Decision: auto dispatch requires each dimension to be at least 32 for already
native-compatible operands/output, or at least 128 when packing is needed. The
32³ heap case has no demonstrated native benefit; leave it in Java. These are
conservative provisional thresholds, not universal crossovers. Forced modes remain
available for reproducible workload-specific testing. Broader rectangular, batched
and platform campaigns are still required before a release performance claim.

## Scalar and memory evidence

The six scalar benchmark paths completed three-fork smoke runs at 65,536 elements.
No speedup or small-array-regression claim follows from their short samples. The
separate native counter probe ran 100 mixed out calls: 100 temporary native leases,
zero retained native bytes. This supports deterministic cleanup, not zero allocation.

The Python samples use the same arithmetic inputs, but their configured BLAS is
recorded separately. They do not establish the same-BLAS 1024² target.

## Release gates still open

The proposal targets for 1M add/multiply/sum, int32 sum, allocating operations,
layout sensitivity and 1024² same-BLAS matmul require a stable reference machine,
comparable M1/candidate runs and agreed regression budgets. They remain unverified.
No correctness, memory or fallback gate is waived to compensate for a missing
performance campaign. The PR must remain draft until outstanding evidence is reviewed.
